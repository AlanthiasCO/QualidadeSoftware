# Contribuição

## Antes de começar

1. Leia `README.md`.
2. Leia `docs/TODO.md`.
3. Para RQ4, leia `docs/CODEBOOK_RQ4.md` e `docs/RQ4_GUIDE.md`.
4. Não altere SHAs congelados ou filtros metodológicos sem discussão da equipe.

## Fluxo sugerido

- crie uma branch por tarefa;
- faça commits pequenos e descritivos;
- abra PR explicando o que mudou e qual item do TODO foi atendido;
- não versione `repos/`, `outputs*/`, caches, logs ou ambientes virtuais;
- evidências qualitativas devem ser rastreáveis por SHA/URL/issue/PR.

## Convenção simples de branches

```text
rq4/<sistema>-avaliacao
results/rq1-redacao
results/rq2-redacao
results/rq3-redacao
paper/metodologia
paper/discussao
fix/<descricao>
```

## RQ4

Cada avaliador deve preencher somente suas próprias colunas em `results/rq4/rq4_avaliacao.csv` até a etapa de consenso.
